HOW IT WORKS

The 5 Core Optimization Pillars

Alloy optimizes prompt payloads in microseconds before network dispatch with zero external dependencies.

01

AST & Code-Safe Compressor

Safely collapses multiline string padding and redundant spaces in natural prose while strictly preserving Python, YAML, and code blocks inside ```fences```.

02

Embedded JSON Minifier

Balanced-bracket parser automatically finds stringified JSON snippets inside instructions and strips indentations and spaces, reducing structured contexts by up to 35%.

03

KV-Cache Prefix Alignator

Stabilizes prompt prefixes so provider KV-caches (Google, OpenAI, Anthropic) achieve maximum cache hit ratios, preventing dynamic timestamps from breaking the cache chain.

04

Deterministic LRU Cache

Key-order-agnostic SHA-256 in-memory cache intercepts duplicate UI queries, user retry loops, and idempotent calls within configurable TTLs, returning in 0ms.

05

Output Token Budget Guardrail

Enforces dynamic max_tokens completion caps to prevent expensive 3x–5x priced output token waste caused by unneeded conversational filler.

06

Universal Runtime Support

Written in modern ECMAScript with native Node.js crypto and WebCrypto fallbacks. Runs universally in Node.js, Bun, Deno, Next.js Edge, and browser clients.

INTEGRATION GUIDE

Drop-In Integration in Under 2 Minutes

Alloy integrates seamlessly with your existing provider SDKs without altering your application logic. 

import { GoogleGenAI } from '@google/genai';
import { Alloy } from 'alloy-sdk';

const ai = new GoogleGenAI({ apiKey: process.env.GEMINI_API_KEY });
const alloy = new Alloy({
  defaultProvider: 'gemini',
  defaultModel: 'gemini-2.5-flash',
  cacheTTLMs: 300000 // 5-minute memory cache
});

// Automatic role mapping ('assistant' ➔ 'model') & systemInstruction separation
const response = await alloy.execute(
  async (payload) => {
    return await ai.models.generateContent({
      model: 'gemini-2.5-flash',
      contents: payload.contents,
      config: {
        systemInstruction: payload.systemInstruction,
        maxOutputTokens: payload.maxOutputTokens
      }
    });
  },
  {
    messages: [
      { role: 'system', content: 'You are an enterprise underwriting assistant.' },
      { role: 'user', content: 'Audit payload: { "riskScore": 12, "active": true }' }
    ]
  }
);

console.log(response.text);
console.log(response._alloyMeta); // { cacheHit: false, savedTokens: 48, costSavedUSD: 0.000004 }
import OpenAI from 'openai';
import { Alloy } from 'alloy-sdk';

const openai = new OpenAI();
const alloy = new Alloy({ defaultProvider: 'openai', defaultModel: 'gpt-4o' });

// Strict prefix stabilization: [System ➔ Static ➔ Conversation turns]
const response = await alloy.execute(
  async (payload) => {
    return await openai.chat.completions.create({
      model: 'gpt-4o',
      messages: payload.messages,
      max_tokens: payload.max_tokens
    });
  },
  {
    messages: [
      { role: 'system', content: 'You are a code refactoring expert.' },
      { role: 'user', isStatic: true, content: 'API Guidelines: ...' },
      { role: 'user', content: 'How do I handle connection retries?' }
    ]
  }
);
import Anthropic from '@anthropic-ai/sdk';
import { Alloy } from 'alloy-sdk';

const anthropic = new Anthropic();
const alloy = new Alloy({ defaultProvider: 'anthropic' });

// Injects cache_control: { type: 'ephemeral' } on static anchors
const response = await alloy.execute(
  async (payload) => {
    return await anthropic.messages.create({
      model: 'claude-3-5-sonnet-20241022',
      system: payload.systemInstruction,
      messages: payload.messages,
      max_tokens: 300
    });
  },
  {
    messages: [
      { role: 'system', content: 'You are a legal document summarizer.' },
      { role: 'user', isStatic: true, content: 'Contract reference clauses...' },
      { role: 'user', content: 'Summarize section 4.2.' }
    ]
  }
);
import { Alloy } from 'alloy-sdk';

const alloy = new Alloy({ defaultProvider: 'gemini' });

// Pure optimization mode without executing network requests
const { messages, systemInstruction, telemetry } = alloy.optimize([
  { role: 'system', content: 'You are a support bot.' },
  { role: 'user', content: 'User details:\n  {\n    "id": 9921,\n    "tier": "enterprise"\n  }' }
]);

console.log('Optimized Payload:', messages);
console.log('Reduction:', telemetry.reductionPercent + '%');
console.log('Tokens Saved:', telemetry.savedTokens);

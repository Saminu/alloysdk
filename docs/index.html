comput-gateway.py
from openai import OpenAI
import os

client = OpenAI(
  base_url="https://your-gateway.example/v1",
  api_key=os.environ["COMPUT_API_KEY"],
)

response = client.chat.completions.create(
  model="gpt-4o-mini",
  messages=[{"role": "user", "content": "Hello via COMPUT Gateway proxy!"}],
  max_tokens=150,
)

print(response.choices[0].message.content)

In your app.
At your edge.

Use COMPUT SDK (currently published as alloy-sdk) where you own the code, or COMPUT Gateway for centralized control. Either way, requests become leaner before they reach a provider.

COMPUT SDK / quickstart.jsNODE
import { Alloy } from 'alloy-sdk';

const alloy = new Alloy({
  defaultProvider: 'vllm',
  cacheTTLMs: 300000
});

const response = await alloy.execute(
  payload => client.chat.completions.create(payload),
  { messages },
  { provider: 'vllm' }
);

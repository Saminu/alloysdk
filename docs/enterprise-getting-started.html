STEP 1

Store your Alloy API key.

Use the key assigned to your organization. Keep it in your deployment environment rather than in source control.

export ALLOY_API_KEY="your-organization-key"
Why one key?AlloyAPI uses it to associate requests with your organization’s routing and efficiency policies.

STEP 2

Point your client to AlloyAPI.

Change the base URL and API key. The rest of your request shape stays compatible with the OpenAI SDK.

from openai import OpenAI
import os

client = OpenAI(
  base_url="https://alloyapi.ai.studio/v1",
  api_key=os.environ["ALLOY_API_KEY"],
)
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://alloyapi.ai.studio/v1",
  apiKey: process.env.ALLOY_API_KEY,
});

STEP 3

Send a standard request.

Choose a model permitted by your organization’s route policy. Alloy applies configured optimization, routing, and telemetry before the provider receives the request.

response = client.chat.completions.create(
  model="gpt-4o-mini",
  messages=[{"role": "user", "content": "Summarize this account."}],
  max_tokens=150,
)

print(response.choices[0].message.content)
✓Your existing messages, tools, streaming, and response handling remain in the same client workflow.

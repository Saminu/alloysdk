STEP 1

Store your COMPUT API key.

Use the key assigned to your organization. Keep it in your deployment environment rather than in source control.

export COMPUT_API_KEY="your-organization-key"
Why one key?COMPUT Gateway uses it to associate requests with your organization’s routing and efficiency policies.

STEP 2

Point your client to COMPUT Gateway.

Replace https://your-gateway.example/v1 with the gateway URL shown in your dashboard, then set your API key. The example domain is a placeholder, not a live endpoint.

from openai import OpenAI
import os

client = OpenAI(
  base_url="https://your-gateway.example/v1",
  api_key=os.environ["COMPUT_API_KEY"],
)
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://your-gateway.example/v1",
  apiKey: process.env.COMPUT_API_KEY,
});

STEP 3

Send a standard request.

Choose a model permitted by your organization’s route policy. COMPUT applies configured optimization, routing, and telemetry before the provider receives the request.

response = client.chat.completions.create(
  model="gpt-4o-mini",
  messages=[{"role": "user", "content": "Summarize this account."}],
  max_tokens=150,
)

print(response.choices[0].message.content)
✓Your existing messages, tools, streaming, and response handling remain in the same client workflow.

STEP 4
